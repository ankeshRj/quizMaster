# QuizMaster -- Python Quiz Game

QuizMaster is an interactive Python-based quiz game that supports
**single-player** and **two-player** modes.\
Players answer multiple‑choice questions, and the game keeps track of
scores and announces the winner.

------------------------------------------------------------------------

## 🚀 Features

-   10 general knowledge questions\
-   Single-player mode\
-   Two-player alternating turn mode\
-   Input validation\
-   Score tracking\
-   Clean and beginner‑friendly Python code

------------------------------------------------------------------------

## ▶️ How to Run

1.  Make sure Python is installed.
2.  Save the `quiz.py` file in a folder.
3.  Open a terminal in that folder.
4.  Run the game:
    python3 quiz.py

------------------------------------------------------------------------

## 📝 Game Rules

-   Players must enter valid option numbers.
-   Each correct answer gives **1 point**.
-   In two-player mode, turns alternate after each question.
-   Final results show total scores and declare a winner.

------------------------------------------------------------------------

## ✨ Customization

You can easily modify:

-   Questions inside the `get_questions()` function\
-   Number of players\
-   Game banner or UI text
