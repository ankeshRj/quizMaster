# Project Statement

This project is a Python-based quiz application called **QuizMaster**. It allows users to play in either single-player or two-player mode, answering multiple-choice questions to test their knowledge.

## Features
- Interactive command-line interface.
- Two game modes: Single Player and Two Player.
- Dynamic scoring system.
- Input validation for smooth gameplay.

## Purpose
The purpose of this project is to demonstrate basic Python programming concepts such as:
- Functions
- Loops
- Conditional statements
- User input handling
- Data structures (lists and dictionaries)

## How It Works
1. The game starts by displaying a welcome banner.
2. The user selects a game mode.
3. Player name(s) are entered.
4. Questions are displayed one-by-one with multiple-choice options.
5. Scores are updated based on correct answers.
6. The final result is shown at the end of the quiz.

## Conclusion
QuizMaster is a simple, fun, and educational mini project suitable for beginners learning Python. Enjoy playing and modifying the code to add your own features!
